A source-based study prompt library: one shared master prompt and fourteen selectable blocks for planning, explanation, retrieval, instructor emphasis, assessment and continuity. English is the maintained primary edition; Czech, Russian and Spanish preserve the same workflow.

## Start

Provide your sources, paste block 1, then paste the selected mode. Replace only the bracketed fields you know. Do not paste all modes as one instruction. To resume in a new chat, provide the master prompt, sources and the previous handoff.

[MASTER PROMPT AND STUDY MODES NOT JUST FOR GEMINI NOTEBOOK](MASTER%20PROMPT%20AND%20STUDY%20MODES%20NOT%20JUST%20FOR%20GEMINI%20NOTEBOOK.md)

## Compatibility and status

Intended for Gemini Notebook and adaptable to ChatGPT, Claude, Gemini and other text assistants with access to your materials. Source citations, attachments and context retention depend on the host. No live provider tests or educational efficacy study have been performed. The files are portable prompt libraries; they do not install an agent skill or activate a tool automatically.
