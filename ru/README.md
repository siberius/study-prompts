# Учебные промпты

Версия: 1.0.0 · 2026-11-05

Библиотека для учёбы по источникам: общий основной промпт и пятнадцать выбираемых блоков для планирования, объяснения, воспроизведения, акцентов преподавателя, оценки и продолжения работы. Основная поддерживаемая версия английская; чешская, русская и испанская сохраняют тот же порядок работы.

Luděk Sušický

biolog, středoškolský a vysokoškolský učitel informatických předmětů

## Начало

Предоставьте источники, вставьте блок 1, затем выбранный режим. Заполняйте только известные поля в скобках. Не вставляйте все режимы одной командой. В новом чате предоставьте основной промпт, источники и запись предыдущего занятия.

## Совместимость и статус

Предназначено для Gemini Notebook и адаптируемо для ChatGPT, Claude, Gemini и других текстовых помощников с доступом к материалам. Цитирование, вложения и сохранение контекста зависят от приложения. Практические испытания сервисов и исследования образовательной эффективности не проводились. Файлы являются переносимыми библиотеками промптов; они не устанавливают агентный skill и не активируют инструменты автоматически.
