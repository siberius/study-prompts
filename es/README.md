# Prompts de estudio

Versión: 1.0.0 · 2026-11-04

Biblioteca para estudiar con fuentes: un prompt principal y doce bloques seleccionables para planificación, explicación, recuperación, enfoque del docente, evaluación y continuidad. El inglés es la edición principal mantenida; las versiones checa, rusa y española conservan el mismo procedimiento.

Luděk Sušický

biolog, středoškolský a vysokoškolský učitel informatických předmětů

## Inicio

Proporciona las fuentes, pega el bloque 1 y después el modo elegido. Completa solo los campos conocidos entre corchetes. No pegues todos los modos como una sola instrucción. En un chat nuevo proporciona el prompt principal, las fuentes y el registro anterior.

[MATSER PROMPT Y MODOS DE ESTUDIO NO SOLO PARA NOTEBOOKLM](MATSER%20PROMPT%20Y%20MODOS%20DE%20ESTUDIO%20NO%20SOLO%20PARA%20NOTEBOOKLM.md)

## Compatibilidad y estado

Pensado para NotebookLM y adaptable a ChatGPT, Claude, Gemini y otros asistentes de texto con acceso a los materiales. Las citas, los adjuntos y la conservación del contexto dependen de la aplicación. No se han realizado pruebas prácticas de proveedores ni estudios de eficacia educativa. Los archivos son bibliotecas portátiles de prompts; no instalan un skill de agente ni activan herramientas automáticamente.
