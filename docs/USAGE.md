## Example

After the shared master prompt, paste block 2 with your topic and any known exam requirements. Then select block 3 to plan or block 7 to practice. Block 12 creates a record to save yourself; it does not promise automatic persistence.

## Other AI applications

Provide readable sources through the host's supported mechanism. Check which materials are available before asking for source-based judgments. If native citations are missing, request an identifiable document and passage; a fabricated page number is not an acceptable substitute. Split large materials into relevant portions when needed and state what was omitted. Do not assume a source upload, context capacity, internet access or memory feature from a model name. These are adaptation instructions, not a claim of tested compatibility.

## Translation and release maintenance

Maintain the English source first, then review all three translations for the same decisions, help conditions, assessment boundaries and source rules. Keep the 15 block numbers aligned. Translate placeholders and prose while preserving the author's name and canonical biography. Update links after renames. CC0 covers original project text and translations; do not relicense external materials.

Before a release, inspect links, fenced blocks, versions, attribution and license notices. Record actual behavioral trials separately from structural review. Suggested trials: startup with incomplete sources; equivalent correct answer; help after a failed attempt; contradictory sources; mock-exam mode switch; handoff in a fresh chat. Record host, model label if known, date, language, supplied materials and observed failures. This release has no live Gemini Notebook or other-provider test results.

## Two paths and the final record

Block 5 offers a Socratic path and a supported explanation path. The former follows the learner's responses without supplying the conclusion; an explicit request for explanation switches paths. Preserve the help history. Feynman explanation can follow either path.

At the end of a meaningful activity, summarize goal, demonstrated performance, assistance conditions, observable change, open issues and one next step. Adapt evidence to the method using the shared master prompt. Invite reflection when appropriate, but do not block ending a session. A handoff extends the same record with sources and a pending step. These are working records within accessible context, not automatic persistent storage or proof of lasting mastery.

The university profile preserves disciplinary depth without compulsory Bloom progression. Blocks 14 and 15 add case synthesis and academic defense. Neither invented cases nor generated dialogue are measurements or official assessment.

## Starting from the materials

After block 1, the tutor first reviews accessible content and states its coverage and gaps. It then offers two or three suitable learning paths, explaining fit, learner activity and evidence, and recommends one. Choose a path, using the corresponding numbered block when helpful. The tutor waits for this choice. A method you already chose is respected; an optional entry task is useful only when missing prior-knowledge evidence changes the recommendation. Missing sources must be requested, not inferred from file names.
